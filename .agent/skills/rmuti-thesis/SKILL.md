# สกิลการจัดทำปริญญานิพนธ์ มทร.อีสาน ขอนแก่น (RMUTI Thesis Guideline)

สกิลนี้สร้างขึ้นเพื่อกำกับการเขียนและจัดรูปเล่มปริญญานิพนธ์ (Senior Project / Thesis) สำหรับ **มหาวิทยาลัยเทคโนโลยีราชมงคลอีสาน วิทยาเขตขอนแก่น** โดยอ้างอิงจาก:
1. **คู่มือการพิมพ์ปริญญานิพนธ์ (ฉบับปรับปรุง พ.ศ. 2566)**
2. **ไฟล์เล่มปริญญานิพนธ์จริงที่ผ่านการประเมินและตีพิมพ์แล้ว (สาขาวิชาวิศวกรรมคอมพิวเตอร์)**

> **ลำดับความสำคัญ: ยึดเล่มรุ่นพี่ (`input/reference/ไฟล์เล่มรุ่นพี่ที่ตรวจผ่านแล้ว.docx`) เป็นหลัก** ทั้งรูปแบบ โครงหัวข้อ และวิธีเขียน ถ้ากฎในไฟล์นี้ขัดกับเล่มรุ่นพี่ ให้ทำตามเล่มรุ่นพี่ และต้องเปิดบทเดียวกันของเล่มรุ่นพี่ดูก่อนเขียนทุกบท

เมื่อใดก็ตามที่มีการร่างเนื้อหาปริญญานิพนธ์ ตรวจทาน หรือสร้างไฟล์ Microsoft Word (`.docx`) ให้ปฏิบัติตามกฎเกณฑ์ในคู่มือนี้อย่างเคร่งครัด

## 1. ข้อกำหนดการตั้งค่าหน้ากระดาษและตัวอักษร (Document Formatting)

### 1.1 กระดาษและแบบอักษร (Font & Paper)
- **ชนิดกระดาษ**: กระดาษขาวมาตรฐาน A4 (80 แกรม) พิมพ์หน้าเดียว
- **แบบอักษรหลัก**: `TH SarabunPSK` (หรือ `TH Sarabun New`) ตลอดทั้งเล่ม
- **ขนาดตัวอักษร**:
  - **เนื้อความทั่วไป**: ขนาด `16pt` ตัวปกติ (Normal)
  - **บทที่ X / ชื่อบท**: ขนาด `16pt` ตัวหนา (Bold) จัดกึ่งกลางหน้ากระดาษ
  - **หัวข้อสำคัญ `X.X`**: ขนาด `16pt` ตัวหนา (Bold) ชิดซ้าย
  - **หัวข้อ `X.X.X` ลงไป**: ขนาด `16pt` **ตัวธรรมดาเสมอ** (ดูข้อ 3.2)
  - **คำบรรยายภาพและตาราง**: ขนาด `16pt` (อนุโลมให้ใช้ `14pt` ได้หากตารางมีเนื้อหาแน่น แต่ต้องอ่านชัดเจน)
- **การจัดแนวข้อความ (Alignment)**:
  - ให้ตั้งเป็น **"กระจายแบบไทย" (Thai Distributed: `w:jc w:val="thaiDistribute"`)** ตามคู่มือ มทร.อีสาน พ.ศ. 2566 ซึ่งจัดให้ขอบขวาตรงเรียบเสมอกัน
  - **การเรนเดอร์ภาษาไทยใน Word**: ต้องกำหนดแท็ก Complex Script (`<w:cs/>`, `<w:rFonts w:hint="cs" w:cs="TH SarabunPSK"/>`, `<w:szCs/>`) และ `<w:lang w:val="en-US" w:eastAsia="en-US" w:bidi="th-TH"/>` เสมอ เพื่อให้ Uniscribe ตัดคำภาษาไทยได้เป็นธรรมชาติและสระไม่ลอย/ไม่ยืด
  - **ข้อห้ามเรื่องการเคาะวรรค**: ห้ามเคาะเว้นวรรคเทียมกลางประโยคภาษาไทยต่อเนื่อง เพราะการกระจายแบบไทยจะขยายช่องว่างเหล่านั้นจนห่างผิดปกติ
- **ระยะห่างบรรทัด (Line Spacing)**:
  - 1 บรรทัด หรือบรรทัดเดียว (Single Spacing) ไม่เพิ่ม Space After/Before มากเกินไป

## 2. การลำดับหน้าและตำแหน่งเลขหน้า (Page Numbering)

- **ตำแหน่งเลขหน้า**: มุมบนขวา ห่างจากขอบบน 2.54 ซม. และห่างจากขอบขวา 2.54 ซม. ฟอนต์ `TH SarabunPSK 16pt`
- **ส่วนหน้า (Preliminary Pages)**: 
  - ใช้พยัญชนะไทย: `ก, ข, ค, ง, จ, ฉ, ช, ซ, ฌ, ญ, ฎ, ฏ, ฐ`
  - เริ่มนับตั้งแต่ **ปกในภาษาไทย** เป็นหน้า (ก)
  - **หน้าห้ามพิมพ์แสดงเลขหน้า**: ปกในไทย (ก), ปกในอังกฤษ (ข), ใบรับรอง (ค), สารบัญหน้าแรก (ช), สารบัญตารางหน้าแรก (ฌ), สารบัญรูปหน้าแรก (ฎ) (ให้นับหน้า แต่ซ่อนเลข)
  - **หน้าที่เริ่มพิมพ์แสดงเลขหน้า**: บทคัดย่อ (ง), Abstract (จ), กิตติกรรมประกาศ (ฉ), สารบัญหน้าถัดไป (ซ), สารบัญตารางหน้าถัดไป (ญ), สารบัญรูปหน้าถัดไป (ฏ)
- **ส่วนเนื้อความและท้ายเล่ม (Body & Back Matter)**:
  - ใช้เลขอารบิก: `1, 2, 3, ...`
  - เริ่มนับตั้งแต่หน้าแรกบทที่ 1 ไปจนถึงหน้าสุดท้ายของประวัติผู้เขียน
  - **หน้าห้ามพิมพ์แสดงเลขหน้า**: หน้าแรกของบททุกบท (บทที่ 1, 2, 3, 4, 5), หน้าแรกของบรรณานุกรม, หน้าแรกของแต่ละภาคผนวก, หน้าแรกประวัติผู้เขียน (ให้นับหน้า แต่ซ่อนเลข)
  - หน้าถัดไปของแต่ละบทให้แสดงเลขหน้าตามปกติ

## 3. กฎการย่อหน้า หัวข้อ และการเว้นวรรค (Headings & Indentation)

### 3.1 ระยะย่อหน้า (Indents)
- **ระยะ 0 ซม. (ชิดขอบซ้าย)**: หัวข้อสำคัญ
- **ระยะ 1.8 ซม. (~0.71 นิ้ว)**: หัวข้อสำคัญลำดับต่อมา และ **ระยะย่อหน้าบรรทัดแรกของเนื้อความ (First line indent)**
- **ระยะ 2.8 ซม.**: หัวข้อรอง
- **ระยะ 4.2 ซม.**: หัวข้อย่อย
- **ระยะ 4.7 ซม.**: หัวข้อย่อยลำดับถัดไป (ระยะสุดท้ายที่อนุญาตให้ย่อ)

### 3.2 การขึ้นบท ลำดับชั้นหัวข้อ และการใช้ตัวหนา (Heading Hierarchy & Weight)
การเรียงลำดับหัวข้อตามโครงสร้าง: `บทที่ X` > `X.X` > `X.X.X` > `X.X.X.X` > `X.X.X.X.X`

- **บทที่ X**: กึ่งกลางหน้ากระดาษ ขนาด 16pt **ตัวหนา (Bold)**
- **ชื่อบท**: บรรทัดต่อมากึ่งกลางหน้ากระดาษ ขนาด 16pt **ตัวหนา (Bold)** (หากยาวเกิน 1 บรรทัด ให้จัดเป็นทรงสามเหลี่ยมกลับหัว)
- **X.X (หัวข้อสำคัญ)**: ชิดขอบซ้ายระยะ 0 ซม. ขนาด 16pt **ตัวหนา (Bold)** เช่น `1.1 ความเป็นมาและความสำคัญของปัญหา`, `1.3 ขอบเขตของโครงงาน`
- **X.X.X (หัวข้อสำคัญลำดับต่อมา)**: ย่อหน้าระยะ 1.8 ซม. ขนาด 16pt **ตัวธรรมดา (Normal / ไม่หนา)** เช่น `1.3.1 ด้านสถาปัตยกรรมระบบและฐานข้อมูล`
- **X.X.X.X (หัวข้อรอง)**: ย่อหน้าระยะ 2.8 ซม. ขนาด 16pt **ตัวธรรมดา (Normal / ไม่หนา)** เช่น `1.3.1.1 พัฒนาระบบตามสถาปัตยกรรมแบบ Multi-Tenant...`
- **X.X.X.X.X (หัวข้อย่อย)**: ย่อหน้าระยะ 4.2 ซม. ขนาด 16pt **ตัวธรรมดา (Normal / ไม่หนา)**
- **X.X.X.X.X.X (หัวข้อย่อยลำดับถัดไป)**: ย่อหน้าระยะ 4.7 ซม. ขนาด 16pt **ตัวธรรมดา (Normal / ไม่หนา)** (ระยะสุดท้ายที่อนุญาตให้ย่อหน้าตามคู่มือ)
- ⚠️ **กฎเหล็กเรื่องตัวหนา**: ทำตัวหนาเฉพาะ `บทที่ X`, `ชื่อบท`, และหัวข้อหลัก `X.X` (Level 2) เท่านั้น ตั้งแต่ระดับ `X.X.X` (Level 3 เช่น `1.3.1`) เป็นต้นไปให้ใช้ตัวธรรมดา (Normal) ทั้งหมด

### 3.3 กฎการขึ้นบรรทัดใหม่ของหัวข้อย่อยและรายการ (Line Wrapping for Numbered Items)
- **บรรทัดแรก (Line 1)**: เริ่มต้นย่อหน้าระยะตามระดับหัวข้อ เช่น 1.8 ซม. สำหรับ 3 หลัก (`1.2.1`, `1.4.1`) หรือ 2.8 ซม. สำหรับ 4 หลัก (`1.3.1.1`) (`first_line_indent = Cm(indent_cm)`)
- **บรรทัดที่สองเป็นต้นไป (Line 2+)**: **ต้องกลับมาชิดกั้นหน้าซ้ายสุดระยะ 0 ซม. เสมอ (`left_indent = Cm(0)`)**
- ❌ **ข้อห้ามเด็ดขาด**: **ห้ามใช้การเยื้องแบบ Hanging Indent** (ที่ให้บรรทัดที่ 2 เยื้องหลบไปตรงกับอักษรตัวแรกของบรรทัดที่ 1) เนื่องจากขัดต่อรูปแบบมาตรฐานในคู่มือ มทร.อีสาน พ.ศ. 2566 (หน้า 57-58 รูปที่ 15 และ 16) และคำสั่งการแก้ไขของอาจารย์

### 3.4 การเว้นวรรคและการตัดคำ (Spacing & Typography)
- **เว้นวรรค 1 ช่วง** (เคาะ space 1 ครั้ง) ได้เฉพาะกรณีต่อไปนี้:
  - หลังเครื่องหมาย `,` `;`
  - หน้าและหลังไม้ยมก (ๆ)
  - ระหว่างคำไทยกับคำอังกฤษ
  - เมื่อจบประโยคหรือเปลี่ยนใจความ
  - ระหว่างรายการที่แจกแจง เช่น "ชื่อ ราคา และรายละเอียด"
- **ห้ามเว้นวรรคกรณีอื่นกลางประโยคไทย** เพราะ thaiDistribute จะถ่างช่องว่างนั้นจนห่างผิดปกติ
- ห้ามเคาะ 2 ครั้งติดกันในเนื้อความ ยกเว้นระหว่างเลขหัวข้อกับข้อความของหัวข้อระดับ `X.X.X` ลงไป เช่น `1.2.1␣␣เพื่อ...` และหลังเลขรูป/ตาราง
- **การตัดคำ**: ไม่ตัดคำระหว่างบรรทัดให้เสียความหมาย หากคำยาวเกินบรรทัดให้ปัดไปขึ้นบรรทัดใหม่ ห้ามมีคำโดดตัวเดียว

## 4. กฎการใส่รูปภาพ ตาราง และสมการ (Tables, Figures, Equations)

### 4.1 รูปภาพ (Figures)
- รหัสกำกับ: `รูปที่ [เลขบท].[ลำดับภาพในบท]` เช่น `รูปที่ 3.1`, `รูปที่ 3.2` (หากมีภาพย่อย ใช้ ก, ข เช่น `รูปที่ 3.1 (ก)`)
- **ตำแหน่งคำบรรยายภาพ**: อยู่ **"ใต้รูปภาพ"** และจัด **"กึ่งกลางหน้ากระดาษ"**
- รูปแบบ: `รูปที่ 3.1  สถาปัตยกรรมของระบบจัดการสินค้า` (เว้นวรรค 2 เคาะหลังหมายเลขรูป)
- **ไม่ต้องเว้นบรรทัด** ระหว่างรูปภาพกับชื่อรูป
- กรณีนำภาพมาจากแหล่งอื่น: ใส่ที่มาต่อท้าย เช่น `(ที่มา: ประภาส, 2566)`

### 4.2 ตาราง (Tables)
- รหัสกำกับ: `ตารางที่ [เลขบท].[ลำดับตารางในบท]` เช่น `ตารางที่ 3.1`, `ตารางที่ 4.2`
- **ตำแหน่งคำบรรยายตาราง**: อยู่ **"เหนือตาราง"** และจัด **"ชิดขอบซ้าย"**
- รูปแบบ: `ตารางที่ 3.1  ผู้ใช้งาน (users)` (เว้นวรรค 2 เคาะหลังหมายเลขตาราง)
- **ไม่ต้องเว้นบรรทัด** ระหว่างชื่อตารางกับหัวตาราง
- หากตารางยาวข้ามหน้า: หน้าถัดไปให้ใส่หัวตารางซ้ำ และพิมพ์ว่า `ตารางที่ 3.1  ผู้ใช้งาน (users) (ต่อ)`
- **แหล่งที่มาของตาราง**: วางไว้มุมล่างซ้ายใต้ตาราง เช่น `ที่มา: กรมพัฒนาธุรกิจการค้า (2565)`

### 4.3 สมการทางคณิตศาสตร์ (Equations)
- พิมพ์สมการอยู่ตรงกลาง หรือชิดซ้าย โดยมีเลขสมการอยู่ในวงเล็บติดชิดขอบขวาของหน้ากระดาษ เช่น `(3.1)`
- เมื่อมีตัวแปรเป็นครั้งแรก ต้องมีคำอธิบายใต้สมการ:
  ```text
  เมื่อ
      σ   แทน   ความเค้น (N/mm²)
      F   แทน   แรงตั้งฉาก (N)
      A   แทน   พื้นที่รับแรง (mm²)
  ```

## 5. กฎการเขียนภาษาทางวิชาการและคำทับศัพท์ (Academic Thai Writing)

1. **การใช้ภาษา**: ใช้ภาษาเขียนที่เป็นทางการ ห้ามใช้ภาษาพูด ภาษาแสลง หรือคำฟุ่มเฟือย
   - เขียนกระชับ ตรงประเด็น ไม่ยืดความ
   - **ห้ามขึ้นต้นด้วย "ในปัจจุบัน"** และห้ามใช้ "ประการแรก / ประการที่สอง ..." ให้เขียนเป็นเนื้อความต่อเนื่องแทน
   - **ห้ามมีคำตกบรรทัดสุดท้ายแค่ 1–2 คำ**: ทุกย่อหน้าต้องจบในบรรทัดเดียว หรือบรรทัดสุดท้ายยาวอย่างน้อย 40% ของบรรทัด ถ้า `thesis_build.py` ขึ้น `WARN last line` ให้เรียบเรียงใหม่ให้สั้นลงหรือยาวขึ้น ห้ามใช้วิธีเคาะวรรคหรือ Enter
   - หัวข้อ 1.3 ขอบเขต เขียนเฉพาะภาพรวม เป็นรายการ `1.3.x` ระดับเดียว (ไม่มี 1.3.x.x) ส่วนรายละเอียด เช่น โหมด ค่าตัวเลข และตาราง ให้ไปเขียนในบทที่ 3
   - หัวข้อ 1.1 เขียน 3 ย่อหน้าสั้นๆ ได้แก่ ความเป็นมา → ปัญหา → แนวทางแก้ไข (Chatshop) เท่านั้น
2. **ลดการแปลคำภาษาอังกฤษซ้ำซ้อน (Anti-Redundant Translation)**:
   - **ห้ามใส่วงเล็บภาษาอังกฤษซ้ำซ้อนพร่ำเพรื่อ**: เช่น การพาณิชย์บนสื่อสังคมออนไลน์ (Social Commerce) หรือ การทำงานร่วมกันเป็นทีม (Team Collaboration) ให้ตัดภาษาอังกฤษออก เหลือเพียงภาษาไทยที่สื่อความหมายชัดเจน เพื่อไม่ให้ข้อความดูเหมือนงานแปลของ AI
   - หากคำใดสื่อความหมายได้ดีด้วยภาษาไทยอยู่แล้ว ให้ใช้ภาษาไทยล้วน ไม่ต้องใส่วงเล็บภาษาอังกฤษ
   - หากเป็นชื่อเฉพาะ แบรนด์ หรือเทคโนโลยีมาตรฐาน เช่น LINE Official Account, Facebook Messenger, Flutter, MySQL, MongoDB, Webhook, REST API, SLA, RBAC, JWT ให้ใช้ทับศัพท์ตรงตัวได้ตามปกติ
3. **การทับศัพท์และการสะกดคำ**:
   - คำศัพท์ทางเทคนิคเฉพาะที่นิยมทับศัพท์ (เช่น React, Node.js, REST API, Database Schema, Cloud VPS) ให้เขียนถูกต้องตามหลักสากล
   - คำพหูพจน์ภาษาอังกฤษ เมื่อเขียนทับศัพท์ภาษาไทย **ไม่ต้องเติม "ส" หรือ "ส์"** (เช่น games -> เกม, integrals -> อินทิกรัล)
   - ชื่อเฉพาะ (ชื่อคน, องค์กร, ผลิตภัณฑ์เฉพาะ) ให้เขียนตามชื่อจริง เช่น Google Maps, LINE LIFF

## 7. เครื่องมือสร้างเล่ม (`scripts/thesis_build.py`)

สร้างเอกสารต่อจาก `input/reference/rmuti_thesis_template.docx` (ใช้ style ชุดเดียวกับเล่มรุ่นพี่) หัวข้อจึงใช้ `Heading 1–4` และเลขหัวข้อรันอัตโนมัติ ทำสารบัญอัตโนมัติใน Word ได้ เนื้อหาเขียนเป็นข้อความล้วนที่ `input/chapters/chN.txt` ตามรูปแบบของเล่มรุ่นพี่:

| บรรทัดในไฟล์ | ผลลัพธ์ (ตามเล่มรุ่นพี่) |
|---|---|
| บรรทัด 1 = เลขบท, บรรทัด 2 = ชื่อบท | `Heading 1` → "บทที่ N" ตามด้วยชื่อบท |
| `2.1 ชื่อหัวข้อ` | `Heading 2` (เลขรันเอง), เว้น 1 บรรทัดก่อนหัวข้อ |
| `1.2.1 ข้อความ` ในบทที่ 1 | `Heading 3` (เลขรันเอง) ส่วน `1.3.1.1` เป็น `Heading 4` |
| `2.1.1 ข้อความ` ในบทที่ 2 ขึ้นไป | Normal พิมพ์เลขเอง นำด้วย 1 tab (`2.1.1.1` = 2 tab) |
| ข้อความธรรมดา | Normal นำด้วย 1 tab (ถ้าอยู่ใต้ `X.X.X` ใช้ 2 tab) |
| `@toc` | รายการหัวข้อ `X.X` ทั้งหมดของบท (เหมือนต้นบทที่ 2 ของรุ่นพี่) |
| `1) ข้อความ` | Normal นำด้วย 3 tab (รายการย่อยใต้ `X.X.X.X` แบบรุ่นพี่) |
| `@fig ชื่อรูป` | กรอบ 1×1 มีข้อความ `[ใส่รูป: …]` และคำบรรยาย "รูปที่ N.n  ชื่อรูป" อยู่ในกรอบ (แบบรุ่นพี่) ต้องเอารูปจริงไปวางแทนข้อความในกรอบเอง |
| `@table ชื่อตาราง` ตามด้วยบรรทัด `a \| b \| c` | คำบรรยาย "ตารางที่ N.n  ชื่อ" ชิดซ้ายเหนือตาราง + ตาราง Table Grid บรรทัดแรกเป็นหัวตาราง (ซ้ำทุกหน้า) ตาราง 4 คอลัมน์ = data dictionary, 3 คอลัมน์ = API |

เลขรูปและเลขตารางเป็น field `SEQ` ที่มีค่าเริ่มต้นอยู่แล้ว ใช้ทำสารบัญรูปและสารบัญตารางใน Word ได้ ตอนอ้างถึงในเนื้อหา เช่น "ดังรูปที่ 3.1" ให้พิมพ์เลขเองตามลำดับ

โครงหัวข้อ `X.X` ของบทที่ 2 ให้ทำตามรุ่นพี่ คือ 1 หัวข้อต่อ 1 เทคโนโลยี แล้วแบ่งเป็น คำอธิบาย → `X.X.1 ข้อดี` → `X.X.2 ข้อเสีย` → `X.X.3 การนำไปใช้ในโครงการ` → `X.X.4 ประโยชน์ของการใช้ ... ในโครงการ`

รันจาก root ของ repo:
```bash
python .agent/skills/rmuti-thesis/scripts/thesis_build.py 2 --no-pdf
```
- ได้ไฟล์ `output/Chatshop_บทที่N_<ชื่อบท>.docx` ถ้าเปิดค้างใน Word จะบันทึกเป็น `_new.docx`
- ถ้าไม่ใส่ `--no-pdf` จะสร้าง PDF ผ่าน Word และภาพ PNG ทุกหน้าที่ `process/temp/`
- `check()` ห้ามใช้ตัวหนาหรือ first-line indent แบบกำหนดตรง ให้ใช้ style และ tab เท่านั้น
- ยังไม่รองรับรูปและตาราง (รุ่นพี่ใช้ style `Caption`) ให้เพิ่มเมื่อเริ่มเขียนบทที่ 3
