4
ผลการดำเนินงาน

ผู้จัดทำนำแอปพลิเคชันบนสมาร์ตโฟนและระบบบริการหลังบ้านที่พัฒนาตามบทที่ 3 มาทดลองใช้งานและทดสอบการทำงาน เพื่อตรวจสอบว่าระบบทำงานได้ตามวัตถุประสงค์และขอบเขตของโครงงาน บทนี้แสดงผลการพัฒนา วิธีการทดสอบ และผลการทดสอบ โดยมีหัวข้อดังนี้
@toc

4.1 ผลการพัฒนาระบบ
ผู้จัดทำทดลองใช้งานระบบกับบัญชี LINE Official Account และเพจ Facebook ที่เชื่อมต่อจริง ผลการใช้งานในขั้นตอนหลักมีดังนี้
4.1.1 การรับข้อความจากหลายช่องทาง เมื่อลูกค้าส่งข้อความเข้ามาทางช่องทาง LINE และ Facebook Messenger ข้อความแสดงในกล่องข้อความของแอปพลิเคชันทันที ดังรูปที่ 4.1
@fig ข้อความจาก LINE และ Facebook Messenger ในกล่องข้อความเดียว
4.1.2 Push Notification เมื่อปิดแอปพลิเคชันอยู่และมีข้อความใหม่ สมาร์ตโฟนแสดงการแจ้งเตือน และเมื่อแตะการแจ้งเตือน แอปพลิเคชันเปิดหน้าต่างสนทนานั้น ดังรูปที่ 4.2
@fig Push Notification บนสมาร์ตโฟน
4.1.3 การตอบข้อความและการทำงานของแชทบอท เจ้าหน้าที่ตอบข้อความและแนบรูปภาพจากแอปพลิเคชัน ลูกค้าได้รับข้อความในช่องทางเดิม และในโหมด Suggest แอปพลิเคชันแสดงคำตอบแนะนำจากแชทบอท ดังรูปที่ 4.3
@fig การตอบข้อความและคำตอบแนะนำจากแชทบอท
4.1.4 การเปิดคำสั่งซื้อจากหน้าต่างสนทนา เจ้าหน้าที่เปิดคำสั่งซื้อจากแผ่นข้อมูลลูกค้า ระบบคำนวณยอดรวมและบันทึกคำสั่งซื้อที่ผูกกับบทสนทนา ดังรูปที่ 4.4
@fig การเปิดคำสั่งซื้อจากหน้าต่างสนทนา

4.2 วิธีการทดสอบ
ผู้จัดทำทดสอบระบบด้วยชุดทดสอบอัตโนมัติ แบ่งเป็น 2 ส่วน ดังนี้
4.2.1 การทดสอบระบบบริการหลังบ้าน ใช้ PHPUnit ของ Laravel ทดสอบทั้งระดับฟังก์ชันและระดับการเรียก API ชุดทดสอบใช้ฐานข้อมูล MySQL และ MongoDB สำหรับทดสอบที่แยกจากข้อมูลจริง และจำลองการเรียกบริการภายนอก เช่น LINE Messaging API, Meta Graph API และแบบจำลองภาษา จึงทดสอบซ้ำได้โดยไม่ส่งข้อความถึงลูกค้าจริง
4.2.2 การทดสอบแอปพลิเคชัน ใช้ flutter_test ทดสอบแบบจำลองข้อมูล Repository และวิดเจ็ตของหน้าจอ โดยจำลองการตอบกลับของระบบหลังบ้านแทนการเรียกเครือข่ายจริง
4.2.3 กรณีทดสอบที่นำเสนอ ผู้จัดทำรันชุดทดสอบทั้งหมดเมื่อวันที่ 1 ตุลาคม 2569 และเลือกกรณีทดสอบที่ตรงกับขอบเขตของโครงงานมานำเสนอในรูปแบบตารางกรณีทดสอบ ซึ่งมีหัวข้อดังตารางที่ 4.1
