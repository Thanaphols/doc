บทนำ

1.1 ความเป็นมาและความสำคัญของปัญหา
การซื้อขายสินค้าผ่านแชทได้รับความนิยมอย่างมากในประเทศไทย ลูกค้าสอบถามรายละเอียดสินค้า ขอดูรูปภาพ และตกลงซื้อขายกับร้านค้าผ่าน LINE Official Account, Facebook Messenger และ Instagram ร้านค้าออนไลน์จึงต้องเปิดหลายช่องทางพร้อมกันเพื่อเข้าถึงลูกค้า
เมื่อแต่ละช่องทางมีแอปพลิเคชันของตัวเอง เจ้าหน้าที่ต้องสลับหน้าจอไปมา ข้อความตกหล่นและตอบลูกค้าไม่ทัน เมื่อร้านมีเจ้าหน้าที่หลายคนก็ตอบซ้ำกัน และไม่มีการแบ่งสิทธิ์การเข้าถึงข้อมูล คำถามเดิมต้องพิมพ์ตอบซ้ำทุกวัน การเปิดคำสั่งซื้อยังทำด้วยตนเองในแชท ข้อมูลลูกค้าและคำสั่งซื้อจึงกระจัดกระจาย และร้านค้าไม่รู้ว่าบทสนทนาใดค้างตอบนานเกินไป
ผู้จัดทำร่วมกับผู้ร่วมพัฒนาจึงพัฒนาระบบ Chatshop ซึ่งประกอบด้วยระบบเว็บและแอปพลิเคชันบนสมาร์ตโฟน โดยผู้จัดทำรับผิดชอบระบบเว็บทั้งหมดที่พัฒนาด้วย Laravel ได้แก่ กล่องข้อความที่รวมแชทจากทุกช่องทางไว้ที่เดียว ระบบทีมและสิทธิ์การใช้งาน แชทบอทที่ตอบคำถามจากฐานความรู้ของร้านค้า ระบบจัดการสินค้า ลูกค้า และคำสั่งซื้อ การแจ้งเตือนแชทที่ค้างตอบ รายงานสรุปผล และ REST API ที่แอปพลิเคชันบนสมาร์ตโฟนเรียกใช้

1.2 วัตถุประสงค์ของโครงงาน
1.2.1  เพื่อพัฒนาระบบเว็บที่รวบรวมและตอบข้อความจาก LINE Official Account, Facebook Messenger, Instagram และ WebChat ได้ในหน้าจอเดียวแบบเรียลไทม์
1.2.2  เพื่อพัฒนาระบบรองรับร้านค้าหลายร้าน พร้อมระบบทีม การมอบหมายบทสนทนา และการกำหนดสิทธิ์การใช้งานตามบทบาท
1.2.3  เพื่อพัฒนาแชทบอทที่ตอบคำถามลูกค้าจากฐานความรู้ของร้านค้า และส่งต่อบทสนทนาให้เจ้าหน้าที่เมื่อไม่สามารถตอบได้
1.2.4  เพื่อพัฒนาระบบจัดการสินค้า ข้อมูลลูกค้า และคำสั่งซื้อที่เชื่อมกับหน้าแชท
1.2.5  เพื่อพัฒนารายงานสรุปผลการให้บริการ และพัฒนา REST API ให้แอปพลิเคชันบนสมาร์ตโฟนเรียกใช้ข้อมูลและฟังก์ชันชุดเดียวกับระบบเว็บ

1.3 ขอบเขตของโครงงาน
1.3.1  ระบบเว็บพัฒนาด้วย Laravel จัดเก็บข้อมูลด้วย MySQL และ MongoDB และประมวลผลงานที่ใช้เวลานานในคิวงานเบื้องหลัง
1.3.2  ระบบเชื่อมต่อ LINE Official Account, Facebook Messenger, Instagram และ WebChat ผ่าน Webhook และส่งข้อความตอบกลับผ่าน API ของแต่ละแพลตฟอร์ม
1.3.3  เจ้าหน้าที่ตอบข้อความ ส่งรูปภาพและไฟล์ ติดแท็ก และมอบหมายบทสนทนาได้จากกล่องข้อความเดียว พร้อมค้นหาบทสนทนาย้อนหลังได้
1.3.4  ร้านค้าส่งข้อความบรอดแคสต์ตามกลุ่มลูกค้าได้ และนำเข้าประวัติแชทเดิมจาก Facebook และ Instagram ย้อนหลังได้ไม่เกิน 90 วัน
1.3.5  ร้านค้าเชิญสมาชิกเข้าทีม และกำหนดบทบาทและสิทธิ์ของสมาชิกได้
1.3.6  ร้านค้าตั้งกฎตอบกลับอัตโนมัติตามคีย์เวิร์ดได้
1.3.7  ระบบมีแชทบอทที่ตอบคำถามลูกค้าจากฐานความรู้ของร้านค้า และส่งต่อบทสนทนาให้เจ้าหน้าที่ดูแลต่อเมื่อคำถามอยู่นอกเหนือข้อมูลที่แชทบอทตอบได้
1.3.8  ร้านค้าจัดการสินค้าและข้อมูลลูกค้าได้ และเปิดคำสั่งซื้อจากหน้าแชทได้
1.3.9  ระบบแจ้งเตือนแชทที่ค้างตอบ และแสดงรายงานสรุปผล
1.3.10  ระบบมี REST API ให้แอปพลิเคชันบนสมาร์ตโฟนเรียกใช้ ส่วนตัวแอปพลิเคชันที่พัฒนาด้วย Flutter เป็นขอบเขตของผู้ร่วมพัฒนา

1.4 ประโยชน์ที่คาดว่าจะได้รับ
1.4.1  เจ้าหน้าที่ตอบลูกค้าจากทุกช่องทางได้ในหน้าจอเดียว
1.4.2  ร้านค้าแบ่งงานเจ้าหน้าที่ได้ชัดเจน และควบคุมสิทธิ์ตามบทบาท
1.4.3  ลูกค้าได้รับคำตอบของคำถามที่พบบ่อยทันทีจากแชทบอท
1.4.4  ลดความผิดพลาดในการเปิดคำสั่งซื้อ และบันทึกข้อมูลลูกค้าเป็นระบบ
1.4.5  ผู้ประกอบการติดตามภาพรวมการให้บริการของร้านได้จากรายงานสรุปผล

1.5 นิยามศัพท์เฉพาะ
1.5.1  Chatshop หมายถึง ระบบรวมศูนย์ข้อความและการจัดการคำสั่งซื้อสำหรับธุรกิจออนไลน์ที่พัฒนาในโครงงานนี้ ประกอบด้วยระบบเว็บและแอปพลิเคชันบนสมาร์ตโฟน
1.5.2  Webhook หมายถึง กลไกที่แพลตฟอร์มแชทส่งข้อมูลเหตุการณ์ เช่น ข้อความใหม่จากลูกค้า มายัง URL ของระบบทันทีที่เกิดเหตุการณ์
1.5.3  Multi-Tenant หมายถึง สถาปัตยกรรมซอฟต์แวร์ที่ให้บริการร้านค้าหลายแห่งภายใต้ระบบเดียวกัน โดยข้อมูลของแต่ละร้านค้าแยกออกจากกัน
1.5.4  RBAC (Role-Based Access Control) หมายถึง การควบคุมการเข้าถึงระบบโดยกำหนดสิทธิ์ให้แก่บทบาท แล้วมอบบทบาทให้ผู้ใช้
1.5.5  RAG (Retrieval-Augmented Generation) หมายถึง เทคนิคที่ค้นคืนข้อมูลที่เกี่ยวข้องจากฐานความรู้ก่อน แล้วส่งให้แบบจำลองภาษาใช้ประกอบการสร้างคำตอบ
