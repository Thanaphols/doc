1.1.2 ประวัติและลักษณะการดำเนินธุรกิจ
บริษัท ไฮเฟนพลัส จำกัด เป็นบริษัทพัฒนาซอฟต์แวร์ของไทยที่รับพัฒนาซอฟต์แวร์ตามความต้องการของลูกค้ามาตั้งแต่ปี พ.ศ. 2563 โดยเน้นระบบสำหรับธุรกิจค้าขายออนไลน์ ได้แก่ ระบบไลฟ์ขายสินค้า ระบบตรวจสอบการชำระเงิน และระบบทำงานอัตโนมัติ บริษัทเป็น Meta Business Partner และ Meta Tech Provider ที่ผ่านการรับรองด้านการคุ้มครองข้อมูลจาก Meta จึงพัฒนาระบบที่เชื่อมต่อกับแพลตฟอร์มของ Meta ได้
ผลิตภัณฑ์ของบริษัท ได้แก่ CF-SHOPS ระบบจัดการไลฟ์ขายสินค้าและรวบรวมคำสั่งซื้อจากหลายช่องทาง CHECK-SLIP ระบบตรวจสอบสลิปโอนเงินปลอมผ่าน LINE หรือ API Earn-Back โปรแกรมรับเงินคืนจากการซื้อสินค้าและการเดินทาง KITTUNG ระบบขายหน้าร้านสำหรับร้านอาหารและร้านค้า และ Megapic Design บริการออกแบบกราฟิก
1.1.3 ตำแหน่งและงานที่ได้รับมอบหมาย
ผู้จัดทำปฏิบัติงานสหกิจศึกษาในตำแหน่ง Trainee Software Development โดยมีนายนพรัตน์ คำโกแก้ว ตำแหน่ง Software Development เป็นพนักงานที่ปรึกษา ผู้จัดทำได้รับมอบหมายให้พัฒนาแอปพลิเคชันบนสมาร์ตโฟนและระบบบริการหลังบ้านของ Chatshop ซึ่งเป็นผลิตภัณฑ์ที่บริษัทจะให้บริการแก่ร้านค้าออนไลน์

1.2 ความเป็นมาและความสำคัญของปัญหา
การซื้อขายสินค้าผ่านการสนทนาทางแชทได้รับความนิยมอย่างแพร่หลายในประเทศไทย ผู้บริโภคติดต่อสอบถามรายละเอียด ขอชมรูปภาพสินค้า และตกลงซื้อขายกับร้านค้าผ่านสื่อสังคมออนไลน์ ได้แก่ LINE Official Account, Facebook Messenger และ Instagram ร้านค้าออนไลน์จึงจำเป็นต้องเปิดให้บริการพร้อมกันหลายช่องทางเพื่อรองรับกลุ่มลูกค้าได้อย่างทั่วถึง
การสื่อสารและการติดตามงานผ่านสมาร์ตโฟนมีความจำเป็นอย่างยิ่งต่อผู้ประกอบการและพนักงานที่ต้องตอบสนองลูกค้าได้อย่างรวดเร็วตลอดเวลา แต่เนื่องจากแต่ละแพลตฟอร์มมีแอปพลิเคชันแยกจากกัน เจ้าหน้าที่จึงต้องสลับเปิดใช้งานหลายแอปพลิเคชันบนสมาร์ตโฟน ส่งผลให้การแจ้งเตือนตกหล่นและตอบสนองลูกค้าล่าช้า เมื่อมีเจ้าหน้าที่หลายคนช่วยกันดูแลก็เกิดปัญหาตอบข้อความซ้ำซ้อนเนื่องจากไม่มีระบบแบ่งมอบหมายงาน อีกทั้งการเปิดคำสั่งซื้อยังกระทำโดยจดบันทึกแยกส่วน จึงเสี่ยงต่อความผิดพลาดและไม่สามารถติดตามสถานะคำสั่งซื้อที่ผูกกับบทสนทนาได้อย่างเป็นระบบ
จากปัญหาดังกล่าว ผู้จัดทำจึงพัฒนาแอปพลิเคชัน Chatshop ซึ่งเป็นแอปพลิเคชันบนสมาร์ตโฟนที่พัฒนาด้วย Flutter สำหรับเชื่อมต่อกับระบบบริการหลังบ้าน เพื่อรวมศูนย์การรับส่งข้อความจากทุกช่องทางไว้ในกล่องข้อความเดียวแบบเรียลไทม์ พร้อมระบบแจ้งเตือนบนสมาร์ตโฟนแบบ Push Notification เมื่อมีข้อความใหม่หรือแชทค้างตอบ การจัดการสถานะบทสนทนา การกำหนดบทบาทและสิทธิ์ของทีมงาน การจัดการข้อมูลสินค้า ลูกค้า และการเปิดคำสั่งซื้อได้โดยตรงจากหน้าต่างสนทนา รวมถึงการควบคุมโหมดการทำงานของแชทบอทเพื่อช่วยตอบคำถามลูกค้าได้อย่างรวดเร็ว

1.3 วัตถุประสงค์ของโครงงาน
1.3.1  เพื่อพัฒนาแอปพลิเคชันบนสมาร์ตโฟนด้วย Flutter ที่สามารถรวบรวมและตอบกลับข้อความจาก LINE Official Account, Facebook Messenger, Instagram และ WebChat ได้ในหน้าจอเดียวแบบเรียลไทม์
1.3.2  เพื่อพัฒนาระบบรับส่งข้อมูลแบบสองทางผ่าน WebSocket และระบบแจ้งเตือน Push Notification บนสมาร์ตโฟนผ่าน Firebase Cloud Messaging เพื่อให้เจ้าหน้าที่รับทราบข้อความใหม่และการแจ้งเตือนแชทที่ค้างตอบได้อย่างทันท่วงที
1.3.3  เพื่อพัฒนาระบบจัดการบทสนทนา การมอบหมายผู้รับผิดชอบ การคัดกรองและค้นหาบทสนทนา และการควบคุมโหมดการทำงานของแชทบอทผ่านแอปพลิเคชัน
1.3.4  เพื่อพัฒนาระบบจัดการข้อมูลสินค้า ลูกค้า และการเปิดคำสั่งซื้อที่เชื่อมโยงกับบทสนทนาบนแอปพลิเคชัน
1.3.5  เพื่อเชื่อมต่อแอปพลิเคชันบนสมาร์ตโฟนเข้ากับระบบบริการหลังบ้านผ่านส่วนต่อประสานโปรแกรมประยุกต์และระบบยืนยันตัวตนที่มีความปลอดภัย

1.4 ขอบเขตของโครงงาน
1.4.1  แอปพลิเคชันพัฒนาด้วย Flutter และภาษา Dart รองรับการทำงานบนระบบปฏิบัติการ Android และเชื่อมต่อกับระบบบริการหลังบ้านผ่านส่วนต่อประสานโปรแกรมประยุกต์
1.4.2  แอปพลิเคชันยืนยันตัวตนผู้ใช้งานด้วยระบบอีเมลร่วมกับรหัสผ่าน และรองรับการเข้าสู่ระบบด้วยบัญชี Facebook และ Google พร้อมจัดเก็บโทเคนความปลอดภัยบนอุปกรณ์
1.4.3  เจ้าหน้าที่สามารถดูรายการบทสนทนารวมทุกช่องทาง คัดกรองตามช่องทางหรือข้อความที่ยังไม่อ่าน และค้นหาบทสนทนาจากชื่อ ข้อความ หรือแท็กได้จากกล่องข้อความเดียว
1.4.4  เจ้าหน้าที่สามารถตอบกลับข้อความ ส่งรูปภาพ วิดีโอ และไฟล์เอกสาร รวมถึงการตอบกลับข้อความสำเร็จรูปและการอ้างอิงข้อความเดิมได้
1.4.5  ระบบแสดงข้อความเข้าใหม่แบบเรียลไทม์ผ่าน WebSocket และส่งการแจ้งเตือน Push Notification มายังสมาร์ตโฟนเมื่อมีข้อความใหม่หรือมีแชทที่ค้างตอบเกินเกณฑ์ที่กำหนด
1.4.6  เจ้าหน้าที่สามารถล็อกบทสนทนาเพื่อป้องกันการตอบซ้ำซ้อน และมอบหมายบทสนทนาให้แก่สมาชิกในทีมงานตามสิทธิ์ที่ได้รับ
1.4.7  ผู้ใช้งานสามารถเลือกปรับเปลี่ยนโหมดการทำงานของแชทบอท และเรียกดูผลการวิเคราะห์เจตนาหรือข้อมูลสรุปของบทสนทนาได้
1.4.8  เจ้าหน้าที่สามารถดูและแก้ไขข้อมูลลูกค้า จัดการแคตตาล็อกสินค้า และเปิดคำสั่งซื้อสินค้าจากหน้าต่างสนทนาได้โดยตรง
1.4.9  ผู้ใช้งานสามารถตรวจสอบรายงานภาพรวมการให้บริการและสัดส่วนปริมาณข้อความของแต่ละช่องทางได้
1.4.10  ระบบบริการหลังบ้านที่พัฒนาด้วย Laravel ทำหน้าที่ประมวลผลคำขอ จัดการฐานข้อมูล รับส่งข้อมูลกับแพลตฟอร์มภายนอก และเปิดส่วนต่อประสานโปรแกรมประยุกต์ให้แอปพลิเคชันเรียกใช้งาน

1.5 ประโยชน์ที่คาดว่าจะได้รับ
1.5.1  เจ้าหน้าที่สามารถติดตามและตอบข้อความลูกค้าจากทุกช่องทางผ่านสมาร์ตโฟนได้สะดวกรวดเร็วในหน้าจอเดียว
1.5.2  ลดความผิดพลาดและลดความล่าช้าในการตอบสนองลูกค้าด้วยระบบแจ้งเตือน Push Notification และการสื่อสารแบบเรียลไทม์
1.5.3  เพิ่มประสิทธิภาพในการทำงานร่วมกันของทีมงานผ่านการแบ่งมอบหมายหน้าที่และการควบคุมสิทธิ์การเข้าถึงข้อมูล
1.5.4  อำนวยความสะดวกในการเปิดคำสั่งซื้อและบันทึกข้อมูลลูกค้าได้ทันทีระหว่างการสนทนา
1.5.5  ผู้ประกอบการสามารถติดตามสถานะการสนทนาและประสิทธิภาพการดำเนินงานของร้านค้าได้ทุกที่ทุกเวลา

1.6 นิยามศัพท์เฉพาะ
1.6.1  Chatshop หมายถึง แอปพลิเคชันรวมศูนย์ข้อความและการจัดการคำสั่งซื้อสำหรับธุรกิจออนไลน์ที่พัฒนาขึ้นในโครงงานนี้ ซึ่งทำงานบนสมาร์ตโฟนและเชื่อมโยงกับระบบบริการหลังบ้าน
1.6.2  Flutter หมายถึง ชุดพัฒนาซอฟต์แวร์ส่วนต่อประสานผู้ใช้แบบข้ามแพลตฟอร์มที่พัฒนาโดย Google สำหรับสร้างแอปพลิเคชันด้วยภาษา Dart
1.6.3  Riverpod หมายถึง เครื่องมือสำหรับบริหารจัดการสถานะของแอปพลิเคชันในระบบนิเวศของ Flutter ที่มีโครงสร้างแบบไม่ขึ้นต่อบริบทของหน้าจอและรองรับการทำงานแบบไม่ประสานเวลา
1.6.4  Push Notification หมายถึง การส่งข้อความแจ้งเตือนจากเครื่องแม่ข่ายผ่าน Firebase Cloud Messaging มายังสมาร์ตโฟนของผู้ใช้งานโดยตรง แม้ไม่ได้เปิดใช้งานแอปพลิเคชันอยู่ก็ตาม
1.6.5  WebSocket หมายถึง โพรโทคอลการสื่อสารข้อมูลแบบสองทางผ่านการเชื่อมต่อแบบเปิดค้างไว้ระหว่างเครื่องแม่ข่ายกับแอปพลิเคชัน เพื่อการรับส่งข้อมูลแบบเรียลไทม์
