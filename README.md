## 🎯 มาตรฐานการจัดหน้าและรูปแบบเอกสาร (RMUTI 2566)
- **ฟอนต์**: `TH SarabunPSK` ขนาด 16pt (ปกติ/หนา) กำหนดแท็ก `<w:cs/>`, `<w:rFonts w:hint="cs"/>` และ `<w:lang w:bidi="th-TH"/>`
- **การจัดขอบ (Alignment)**: ใช้แบบ **กระจายแบบไทย (Thai Distributed)** (`w:jc w:val="thaiDistribute"`) ขอบขวาตรงเรียบ ช่องไฟสม่ำเสมอ
- **ระยะขอบ (Margins)**:
  - หน้าแรกของแต่ละบท: บน 5.08 ซม. (2 นิ้ว), ล่าง 2.54 ซม., ซ้าย 3.81 ซม. (1.5 นิ้ว), ขวา 2.54 ซม. (ไม่แสดงเลขหน้า)
  - หน้าเนื้อหาถัดไป: บน 3.81 ซม. (1.5 นิ้ว), ล่าง 2.54 ซม., ซ้าย 3.81 ซม., ขวา 2.54 ซม. (แสดงเลขหน้ามุมขวาบน)
- **ระยะย่อหน้า (Indents)**: บรรทัดแรกย่อหน้าเนื้อหา `1.8 ซม.`, หัวข้อย่อย 3 หลักย่อหน้า `1.8 ซม.`, หัวข้อย่อย 4 หลักย่อหน้า `2.8 ซม.`
- **การขึ้นบรรทัดใหม่ของหัวข้อย่อย (Line Wrapping)**: บรรทัดแรกย่อหน้าตามระดับ เมื่อข้อความยาวจนขึ้นบรรทัดที่ 2 เป็นต้นไป ข้อความจะต้อง **ชิดกั้นหน้าซ้ายสุด (0 ซม.)** เสมอ (ห้ามใช้ Hanging Indent เยื้องหลบเลขหัวข้อ)
- **ลำดับชั้นหัวข้อและความหนา (Heading Hierarchy & Weight)**:
  - `บทที่ X` และ `ชื่อบท`: กึ่งกลางหน้ากระดาษ, 16pt, **ตัวหนา (Bold)**
  - `X.X` (หัวข้อสำคัญ Level 2 เช่น 1.1, 1.2, 1.3, 1.4, 1.5): ชิดขอบซ้าย 0 ซม., 16pt, **ตัวหนา (Bold)**
  - `X.X.X` (หัวข้อสำคัญลำดับต่อมา Level 3 เช่น 1.3.1 – 1.3.6): ย่อหน้า 1.8 ซม., 16pt, **ตัวธรรมดา (Normal / ไม่หนา)**
  - `X.X.X.X` (หัวข้อรอง Level 4 เช่น 1.3.1.1): ย่อหน้า 2.8 ซม., 16pt, **ตัวธรรมดา (Normal / ไม่หนา)**
  - `X.X.X.X.X` (หัวข้อย่อย Level 5): ย่อหน้า 4.2 ซม., 16pt, **ตัวธรรมดา (Normal / ไม่หนา)**
  - ⚠️ *ทำตัวหนาเฉพาะ `บทที่ X`, `ชื่อบท`, และหัวข้อหลัก `X.X` เท่านั้น ตั้งแต่ระดับ `X.X.X` (`1.3.1`) เป็นต้นไปให้ใช้ตัวธรรมดา (Normal) ทั้งหมด*
